# Contributing to logql-cheatsheet

Thanks for considering a contribution — this is a small reference doc, so keep changes focused.

## What's here

There's no build step — `README.md` is the whole project.

## What's welcome

- Corrections to any syntax or example (please link the Grafana docs section it's drawn from)
- Additional recipes under [Recipes](README.md#recipes) — combined, real-troubleshooting queries,
  not just syntax restated in isolation
- Fixing anything that's gone stale as LogQL evolves

## What's not in scope

This stays LogQL-specific and stays a single page. PromQL, other query languages, or splitting
into multiple files are out of scope — if you want something broader, it's probably a different
project.

## Submitting

1. Fork the repo and create a branch named `your-username/short-description`.
2. Open a pull request against `master` describing the change.
